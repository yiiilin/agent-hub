# Agent, Skill, and MCP browser workflows

Uses the real console and backend to create and edit Markdown Skills and an
Agent, configure its model and Subagent, bind Skills through the
dedicated dialog, and maintain MCP entries through the table subforms. It also
checks bulk Skill deletion, desktop and 390px layout, browser diagnostics, and
the Historical Session view after deleting an Agent.

Tracing is paused while the MCP plaintext is entered. The dialog is closed or
redacted before tracing resumes so failure screenshots and traces never retain
the generated secret.
