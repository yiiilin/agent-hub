# Permanently erase users and owned data

An Administrator may irreversibly erase a Hub User within that Administrator's authority after confirming the target Username; only a Super Administrator may erase another Super Administrator. Agent Hub immediately blocks login, revokes credentials, and stops active Runs, then uses a retryable deletion job to purge the user's database records, secrets, attachments, local Workspaces, and Session Bundles from object storage; the Username and email become reusable only after the purge completes. No recovery copy is retained, but a minimal audit record containing only the acting administrator, time, and erased internal user identifier remains. As the narrow exception defined by ADR-0025, de-identified Model Token Usage and Model Call Errors remain in their immutable historical ledgers without a recoverable association to the erased user.
