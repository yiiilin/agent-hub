# Separate password registration from password login

Agent Hub keeps self-service Password Registration separate from Local Password Login. Registration is initially available in an empty Hub and is automatically disabled after creation of the first Hub User; an Administrator may later reopen it explicitly, but only while ordinary Local Password Login is enabled. Turning registration off blocks only new public sign-ups: existing password credentials remain usable, Administrators may still provision Hub Users, and LDAP or enabled external Authentication Channels may still create or bind Hub Users. Because V1 performs no email verification, reopening registration deliberately accepts malicious pre-registration of an LDAP user's email and the resulting trusted-email account binding risk; the Administration UI must keep that risk visible. A separate policy disables ordinary password login without disabling a Super Administrator's emergency password path, so changing registration policy cannot unexpectedly lock out existing users.
