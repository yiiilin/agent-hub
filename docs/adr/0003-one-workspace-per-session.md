# Isolate each Session's Workspace and Codex directory

Each Session owns one isolated Workspace, and all Runs in that Session execute serially against the same evolving filesystem. While online, it also uses a separate local Codex directory whose Agent instructions, Skills, configuration, and native conversation files are never shared with another Session. Run records remain execution history rather than storage boundaries; immutable archive generations capture recovery points without creating new logical Workspaces. When the Session goes offline, only the Workspace and Session Recovery Data selected by ADR-0015 enter its bundle; all other Codex-directory content is discarded and regenerated when needed. This replaces per-Run directory copying with a session-level lifecycle, prevents cross-Session configuration leakage, and keeps conversation state aligned with the files Codex sees.
