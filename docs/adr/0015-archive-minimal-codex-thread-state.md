# Archive only Workspace and Session Recovery Data

An offline Session Bundle contains exactly its Workspace and Session Recovery Data. The recovery data consists of a versioned manifest bound to a Hub Session History checkpoint, the Session and Thread identifiers, the native transcript files for that Thread, and a consistent snapshot of the native index data required to find and resume it. The runtime stops the Session's app-server before taking this checkpoint so no live database or transcript write can be omitted. Codex authentication files, model proxy credentials, MCP secrets, logs, caches, shell snapshots, Skills, Hub-regenerable Agent configuration, and every other runtime file are excluded. This supersedes ADR-0004's exclusion of all native Codex conversation data because that approach cannot preserve one Thread across offline restoration.

The archive has exactly three top-level entries. `workspace/` contains the complete Workspace, including hidden files and `.git`, without `.gitignore`-based filtering; user-created secrets inside the Workspace are therefore included. `manifest.json` binds the Bundle format, Session and Thread identifiers, Hub history checkpoint, Bundle and ownership generations, producing Codex version, creation time, declared sizes, and content checksums. `codex-thread/` contains only the native transcript and index files required to resume that Thread. Packaging accepts ordinary files, directories, and safe symbolic links, and rejects device files, sockets, FIFOs, and paths that could escape the Workspace when restored.

Agent Hub retains only one committed Bundle generation per Session. A replacement uploads under a new object identity while the old Bundle remains current; Hub validates the small commit metadata and successful object write without unpacking or scanning the archive, atomically advances the database pointer, and only then deletes the previous object. Failed or incomplete uploads never become current and are cleaned up, and Agent Hub exposes no Bundle version history or rollback.
